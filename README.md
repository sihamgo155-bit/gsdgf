# CIA Roleplay V3.0

بوابة لعب أدوار خيالية بواجهة عربية/إنجليزية جزئياً، تسجيل دخول بالأكواد، طلبات QCM، لوحة إدارة، إدارة رتب وأكواد ومهام.

## الملفات
- `index.html` — الواجهة.
- `styles.css` — التصميم المتجاوب والحركات.
- `app.js` — وظائف الواجهة.
- `config.js` — إعداد مشروع Supabase.
- `supabase.sql` — الجداول ودوال RPC اللازمة.

## مهم قبل النشر
**الأكواد التي تُنشأ في وضع المعاينة لا تعمل على أجهزة أخرى.** لكي يعمل كود العضو على هاتفه، يجب تهيئة قاعدة بيانات Supabase مشتركة. لا يمكن إنشاء رابط مشروع أو مفتاح حقيقي بالتخمين، لذلك لم أضع بيانات اتصال وهمية.

## إعداد Supabase
1. افتح https://supabase.com/dashboard وأنشئ مشروعاً.
2. من إعدادات المشروع انسخ `Project URL` و`anon/public` أو `publishable key`.
3. ضع القيم في `config.js` مكان `YOUR-PROJECT-REF` و`YOUR_SUPABASE_ANON_PUBLIC_KEY`.
4. افتح **SQL Editor** في مشروع Supabase، الصق محتوى `supabase.sql` كاملاً ثم اضغط **Run**.
5. ارفع جميع الملفات إلى جذر مستودع GitHub Pages أو الاستضافة الثابتة. تأكد من رفع `index.html`, `styles.css`, `app.js`, `config.js`.
6. افتح الموقع بعد النشر، وسجّل دخول الإدارة من زر `CIA ADM` بالكود `1937`.
7. من لوحة الإدارة أنشئ كوداً باسم عضو ورتبته، ثم جرّبه في نافذة خاصة أو جهاز آخر. إذا لم يعمل، افتح Console وتأكد أن إعدادات Supabase صحيحة وأن SQL نفّذ بلا أخطاء.

## وظائف
- الإدارة: مراجعة طلبات الانضمام وقبولها/رفضها.
- إنشاء كود عضو مع الاسم والرتبة.
- تغيير الرتب أو حذف/تعطيل الأكواد.
- إضافة مهام وتحديد المسؤول وتغيير حالة المهمة.
- صفحة تقديم مع اختبار QCM.
- كود الإدارة `1937` مُضاف بواسطة SQL.

## الأمان
- لا تضع `service_role` أو `secret key` في `config.js` أو أي ملف عام.
- `1937` رمز إدارة مشترك حسب طلب المشروع؛ أي شخص يعرفه يمكنه الوصول إلى صلاحيات الإدارة. غيّره قبل فتح الموقع للعامة إذا أمكن.
- هذا مشروع لعب أدوار خيالي وليس موقعاً حكومياً أو نظام هوية حقيقياً.
- لا تخزن كلمات مرور حقيقية أو بيانات شخصية حساسة.
